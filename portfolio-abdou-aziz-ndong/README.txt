OUVRIR LE SITE
1. Décompresser le fichier ZIP.
2. Ouvrir le dossier portfolio-abdou-aziz-ndong-refonte dans Visual Studio Code.
3. Ouvrir index.html.
4. Lancer avec Live Server (ou ouvrir index.html dans un navigateur).
5. Utiliser le menu pour parcourir les six pages.
